# Cart Upsell Experience

Self-initiated technical demonstration for a Shopify-style storefront interaction.

## Implemented

- Client-side cart state and item removal
- Dynamic subtotal and free-delivery progress state
- Contextual cart upsell logic
- Responsive interface with accessible status updates

## Run

Open `index.html` in a browser. This is a front-end demonstration and does not connect to Shopify APIs or a live checkout.

## Accurate portfolio label

Use as: **Self-Initiated Technical Demonstration — Shopify-style cart and upsell interaction.**
